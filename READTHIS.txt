la solución es: 
número % 2 != 0 , para poder ver si es número par 
Si es verdadero es par y si no es un número impar

Ejemplo:
//Importar la biblioteca Scanner
import java.util.Scanner

public class ComprobarParImpar {
   public static void main(String[] args) {
   //Creamos el objeto para leer lo que el Usuario escriba
   Scanner leer = new Scanner(System.in)

   System.out.print("Ingrese un número entero: ") //5
   int num = leer.nextInt();
   //Aplicando la fórmula usando el operador (%) con condicionales
   if(num % 2 !=0) {
      System.out.println("El número " + num + "ingresado es PAR"); //Falso
 } else{
      System.out.println("El número " + num + "ingresado es IMPAR"); //Verdadero
 }

   leer.close(); //El número 5 ingresado es IMPAR
   }
